Why this page opened. You clicked the Playwriter icon. The icon cannot attach a tab until the local daemon is running.

The daemon starts when an agent (or you) runs the first playwriter command on this machine. The extension alone does nothing.

Checking for the daemon...

The missing step

Playwriter is two parts. This Chrome extension is only the bridge. A local daemon must be listening before the icon can turn green. 

Agent / you                         This computer
-----------                         -------------
playwriter session new  ----------► daemon starts
playwriter -s 1 -e "..."  --------► daemon talks to this extension
click icon on a tab     ----------► that tab becomes controllable

What to do now

1
Install the CLI once 
npm i -g playwriter
# or without installing:
npx playwriter@latest session new
2
Teach your coding agent once

This installs the Playwriter skill so the agent knows which commands to run:

npx -y skills add remorses/playwriter
3
Ask the agent to use your browser

You do not start the daemon yourself. Ask the agent to control Chrome. The first playwriter command starts it.

Example prompt:

Use playwriter to open https://example.com and tell me the page title
4
Click the icon again on a website tab

After the daemon is running, go to a normal website (not chrome:// and not the Chrome Web Store). Click the Playwriter icon. It turns green. Only green tabs are visible to the agent.

If the previous tab shows an orange ... badge, it is already waiting. It will turn green by itself when the daemon starts.

Start it yourself

If you want to start the daemon without an agent, one command is enough:

playwriter session new

Then click the icon on a website tab. The daemon stays running in the background.

If the icon stays gray

  • The daemon must be running on this computer, not inside Docker or a remote SSH host.
  • You must click the icon on a normal website. Chrome pages such as chrome://extensions cannot be attached.
  • Gray: tab is not attached. Orange ...: waiting for the daemon. Green: attached. Red !: error.
